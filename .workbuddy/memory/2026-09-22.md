### 二、三卷"缺字"缺陷修复（r75 新发现，重要）
**症状**：编译日志 `Missing character: There is no X in font [lmroman12-regular]` 264 条（book）/
67（female）/ 21（male）。这些字符在 PDF 里**渲染成空白 = 丢知识点**，不是无害警告。
**根因**：preamble 只设了 `setCJKmainfont{SimSun}`，**未设 `setmainfont`**；西文走 Latin Modern，
而 ①②③④⑤⑥、Ⅰ-Ⅻ、α β γ μ ω、≠ ≈ ≤ ≥、─、■、⚠、・ 这些字符两个字体都不覆盖。
**修法（已落地，三卷 preamble 各插 61 行"符号字体回退块"）**：
```latex
\usepackage{newunicodechar}
\newfontfamily\symbolfallback{SimSun}           % 带圈数字/罗马数字/希腊字母/数学符号/制表符/几何图形
\newfontfamily\symbolfallbackx{Segoe UI Symbol} % ⚠
\newunicodechar{①}{{\symbolfallback\char"2460}}   % 其余同理
```
**关键坑（实测得出，勿重复踩）**：
1. `\newunicodechar{・}`（U+30FB）**无效**——xeCJK 把日文中点判为 CJK 字符类，直接交给 SimSun，
   而 SimSun 无此字形；`{\fbj ・}` 与 `{\fbj\char"30FB}` 同样被劫持。`\xeCJKsetcharclass` **不存在**。
   → 最终改为在 `references.bib` 里把 `・` 换成 `·`（U+00B7，实测可显）。
2. **改了 .bib 必须重跑 bibtex**——编译脚本只跑 xelatex，`.bbl` 不会自动更新（否则缺字依旧）。
   命令：`bibtex book` 后再 `_r57_compile.py book 2`。
3. 字体覆盖实测（`_r75_fontprobe.tex` 结论）：SimSun 缺 ・ ⚠ ₂ ⁶ ‧ ⸺；Segoe UI Symbol 缺 Ⅰ-Ⅴ ・；
   Cambria/SimSun-ExtG/DejaVu Sans Mono 都不如 SimSun。**SimSun + Segoe UI Symbol 组合覆盖最全。**
4. 源文本真错（**改源不加白名单**）：book `\ufffd\ufffd疑`→`质疑`；book `CO₂`→`CO$_2$`；
   female `10⁶`→`$10^{6}$`；female `⸺`→`——`；female `‧`→`·`。
