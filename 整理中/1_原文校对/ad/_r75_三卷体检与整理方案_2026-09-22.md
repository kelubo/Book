### 2. 修复"缺字"缺陷（新增发现，属"丢知识点"）
- **症状**：编译日志 264 条（book）/ 67（female）/ 21（male）
  `Missing character: There is no ① in font [lmroman12-regular]`。
  这些字符在 PDF 中**渲染为空白**——读者看不到，等于丢失内容。
- **根因**：preamble 只设 `\setCJKmainfont{SimSun}`，**未设 `\setmainfont`**；西文走 Latin Modern。
  而 ①②③④⑤⑥、Ⅰ-Ⅻ、α β γ μ ω、≠ ≈ ≤ ≥、─、■、⚠、・ 这 25 类字符**两个字体都不覆盖**。
- **修法**：三卷 preamble 各插入 **61 行"符号字体回退块"**（`newunicodechar` → SimSun / Segoe UI Symbol）。
  实测三卷 `Missing character` **全部归零**。
- **另修 5 处源文本真错**（改源而非加白名单）：`��疑`→`质疑`、`CO₂`→`CO$_2$`、
  `10⁶`→`$10^{6}$`、`⺗`→`——`、`‧`→`·`，以及 `references.bib` 中 3 处 `・`→`·`。

## 二、两卷结构诊断（本轮最关键发现）

三卷的边界语义**不相同**：`book.tex` 用 `\part{old}` 划出"待迁移旧区"；
**两卷没有 `\part{old}`，而是「三区结构」**：

| 区 | 位置（female / male） | 体量（female / male） | 是否编译 |
|---|---|---|---|
| ① 文件头注释区 | L1~约280 / L1~约175 | 「建议章节重组方案」 | 否 |
| ② **停用框架区** | L285~6481 / L180~5766 | **6 197 行 / 5 587 行**（5篇11章50节187小节 / 4篇4章34节140小节） | **否**（`\skip…true`） |
| ③ 编译区 | L6490 起 / L5775 起 | — | 是 |
| 　③-a r72 定版骨架 | L6799~7090 / L6051~6237 | **5 篇 12 章，只有标题** | 是 |
| 　③-b `\part*{原始内容}` 旧材料 | L7092~21369 / L6251~8282 | **14 278 行 28 节 / 2 032 行 4 节** | 是 |

### 关键结论
1. **停用框架区是「较早草稿」**（female 11 章 / male 4 章），**不是**待启用的成品；
   **r72 定版骨架（各 12 章）才是目标结构**。→ **不能简单把开关改成 `false`**。
2. 当前 PDF 的正文来自 **③-b 旧材料**，而 r72 骨架（③-a）**只有标题、无正文**，
   因此编译出的目录结构与正文内容**不对应**。
3. **文件内 L6786~6796 的「使用说明」已写明作者的既定流程**：
   把「框架成稿」与「旧区同名节」按名迁入 r72 骨架 → 全部迁完后删除 `\part*{原始内容}` 及以下旧标题行，
   并删除停用框架区。

## 三、两卷 preamble 的编号损坏（作者已标"待授权"，本轮获授权）

```latex
% female L6584-6588 / male L5869-5873 —— 现状（损坏）
\ctexset{
    part/name={。卷},        % ← 应为 {第,篇}
    part/number={\chinese{part}},
    chapter/name={。章},     % ← 应为 {第,章}
    chapter/number={\chinese{chapter}},
    section/name={。节},     % ← 应删除（与 book.tex 对齐，用 ctexbook 默认）
    section/number={\arabic{section}},
    subsection/number={\arabic{section}.\arabic{subsection}},
}
```
**后果**：编译后的目录里章/节编号显示成「**。章一**」「**。节1**」。
（这也是作者在骨架里一律用 `\part*` 规避的原因。）

**另发现一处目录缺陷**：编译区骨架 part1 用 `\part{…}`、part2~5 用 `\part*{…}` + `\addcontentsline`，
→ **part1 的目录项重复出现一次**。

**建议修法**（与 book.tex 对齐）：
```latex
\ctexset{
    part/name={第,篇},  part/number={\chinese{part}},
    chapter/name={第,章}, chapter/number={\chinese{chapter}},
}
```
并**剥离篇标题里冗余的"第一篇："前缀**（否则渲染成"第一篇 第一篇：女性生殖基础"），
同时把 5 个篇统一为 `\part{…}`（去掉重复的 `\addcontentsline`）。
