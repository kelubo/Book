## 四、顺带修复：male.tex 编译损坏（458 → 0 错误）

上轮把停用框架区成稿迁入 male.tex 编译区时，**preamble 未加载 `tcolorbox` / `tabularx`，
也未定义 `\keyword`**，导致 458 个错误（`Environment tcolorbox undefined` ×61、
`Misplaced alignment tab character &` ×205、`Misplaced \noalign` ×53、`Environment tabularx undefined` ×16、
`Undefined control sequence` ×14）。

修复（`_r77_male_fix.py`）：在 `\usepackage{pdfpages}` 之后补 7 行——

```latex
\usepackage{tcolorbox}
\usepackage{tabularx}
\newcommand{\keyword}[1]{\textbf{#1}}
```

另修正 2 处源码笔误：`colframe=red!50~50!black` → `red!50!black`；
标题中未转义的 `&`（`（Orchiectomy & Sexual Function）` → `\&`）。**male 恢复 0 错误**。

## 五、本轮事故与教训（重要，已写入护栏）

**两次踩到同一类坑：块尾紧邻 `\part`（篇分隔行）时被一起搬走/删掉。**

1. 第一次：`\chapter{性爱中的意外与处理}` 的块尾（L7439）正好紧邻 `\part{性传播疾病与防护}`（L7438），
   结果该 `\part` 既被复制进 position.tex，又被从 book.tex 删除。
   原因：校验器把 `\part`/`\chapter` 行都当作"可重建的结构残留"放行——对 `\part` 这是错的。
2. 修复后加了**两重护栏**：
   - `slice_region` / 区间合并：块内**遇到 `\part` 立即截断**，不让它进入块；
   - 移出校验：`\part` 行**不再允许**作为残留；并新增"**`\part` 清单增减必须精确等于预期**"断言
     （目前仅允许删 `\part{第四篇：性交体位与姿势艺术}`）。
3. 恢复流程：从 `*.r77bak_*` 还原源文件 → 重跑 `_r77_build.py apply` → 重跑 `_r77_extract.py apply`。
   **注意：`_r77_extract.py` 对已执行过的源文件不幂等**（锚已不存在），必须先从备份还原再跑。

其余工程约定延续既有铁律：改源文件前先备份、dry-run 双模、写盘前全量断言（换行类型 / 花括号 delta /
结尾 / 环境配对 / 纯 LF / 无 `**` / 无 U+FFFD）。
