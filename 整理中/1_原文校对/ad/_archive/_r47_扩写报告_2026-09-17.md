## 五、问题与修复（本轮唯一一处，文件无损）

**执行器吃掉段间空行**：定版执行器沿用了 r44 的写法

```python
clines = [x.rstrip() for x in content.split("\n") if x.strip()]
```

`if x.strip()` 会把内容内部的空行一并过滤，导致**多段增写被压成一个超长段落**，与全书"段间空行 = 分段"的排版惯例不符。首次 apply 后抽查 L623 区域即发现（L628/629 两段连排）。

处理：从 `_backup_r47/` 恢复三卷 → 改为只裁首尾空行、保留内部空行：

```python
clines = [x.rstrip() for x in content.split("\n")]
while clines and not clines[0].strip(): clines.pop(0)
while clines and not clines[-1].strip(): clines.pop()
ins[pos] = [""] + clines + [""]
```

重跑 dry-run 后增量由 +144 变为 **+180**（多出 36 行 = 36 条各自的段间空行），确认修复生效，再正式 apply。经验已写入技能（安全规则 9 + 校验方式：**dry-run 增量应含段数对应的空行**）。
