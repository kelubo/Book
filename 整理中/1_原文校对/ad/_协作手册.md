## 三、内容去重方法论

### 甄别规则（最重要）

**标题相同 ≠ 重复。** 以下通用小标题在不同父级下多次出现是**正常结构，不许合并**：

> 原因 / 病因 / 分类 / 诊断与治疗 / 诊断与评估 / 临床表现 / 治疗方法 / 治疗方案 / 预防措施 / 使用说明 / 流行病学 / 常见问题 / 促进策略

只处理：**同一父级章节下、同一主题的两套并行版本**。

判断流程：
1. 找出同名标题 → 2. **向前取最近的 `\chapter` 确认父级**（漏这步会误判） → 3. 若父级不同且主题不同 → **不合并** → 4. 拿不准先问用户。

### 标准处置流程

1. 提取两版全文，逐段比对；
2. 以**科学叙事版**为主体，把旧版独有知识点改写并入（保持科学表述）；
3. **顺序不可颠倒：先并入旧版独有内容，再删旧块**（曾因顺序错乱丢失内容）；
4. 旧版数据与主流证据冲突时，**按科学准确优先舍弃旧版数据**；
5. 译文来源、需保留原貌的内容保留原文并加内联编者注；
6. 同步更新受影响的交叉引用与目录；
7. 编译验证。

### 典型可合并信号

- 同一章内出现两套四期／两套分类／两套技巧；
- 旧版残留常表现为**「裸编号行 + itemize」直接贴在 `tcolorbox` 之后**，或 `\subsubsection` 层级错误；
- 删除前必须确认该块内容已被紧邻的新版覆盖，若有独有问题先并入正文。

### 判定「内容缺失」的纪律（2026-10-19 血泪教训）

**词形为 0 ≠ 概念缺失。** 判定某主题「缺失」前，必须穷举其同义词／异译名／缩写后再统计，否则会得出**与事实相反**的结论并向用户误报。

实例（男科缺口扫描，初判 4 项「全书缺失」，逐一核实后**无一成立**）：

| 我搜的词（0 次） | 书中实际用词 | 真相 |
|---|---|---|
| 迟泄 | **延迟射精**（1_male L2134 `\textbf{术语定义}` 正式定义） | 已覆盖，误判 |
| 痛性射精 | **射精疼痛**（1_male 8 处，含 CPPS／神经损伤语境） | 已覆盖，误判 |

纪律：
1. **先列同义词族 → 再统计 → 仍为 0 才报缺失**；
2. 报缺失前先查该概念是否已被**指南淘汰**（缺了反而是对的）；
3. 必须区分「真缺失」与「已由共通卷承担」——按 §一 规则 4 的分工，共通卷承担是**合理**的，不算男/女卷缺口。

### 体量对比的正确指标

**用「中文字符数」，不要用「行数」。** 行数受标记碎片化程度影响会严重失真：1_male / 2_female 实际内容量比（中文字符）为 **2.91×**，而行数比虚高到 **3.64×**（2_female 源码行更短、标记更碎）。页数差异应先算「字符/页」确认排版密度是否一致，再归因到内容量。

## 四、脚本工程规范（血泪教训）

### 读写

```python
# 读：CRLF 文件必须 newline=None，多行锚点才命中
with io.open(SRC, encoding='utf-8', newline=None) as f:
    lines = f.readlines()
# 写：写回 CRLF
with io.open(SRC, 'w', encoding='utf-8', newline='\r\n') as f:
    f.writelines(lines)
```

CRLF 文件的多行锚点**必须**按上面方式读，否则 `\n` 锚点在 `\r\n` 文件里命中 0 次。

### 行号

- PowerShell `Get-Content` 行号为 1-based，与 `lines[n-1]` 对应；
- **`read_file` 在 CRLF 文件上行号有 +1 偏差**，不可作为删除依据；
- 删除块的守卫**必须用行号直接取行**：

```python
def L(n):                 # 取第 n 行（1-based）
    return lines[n - 1]
assert L(6132).startswith('\\subsection{...}')
```

  **不要凭删除量推算行号**——曾连续两次算错，改用 `L(n)` 后一次通过。

### 幂等与安全

- 脚本开头 `shutil.copyfile` 到 Temp 备份；**"恢复→重跑"循环前必须先验证恢复生效**（行数 + 特征串计数），否则会把合并版覆盖进备份造成**备份污染**；
- 批量补丁必须"新串已存在则跳过"（幂等）+ 写 TMP → 读回校验 → `os.replace()`；
- 每个删除块都要有**守卫断言**（上界、下界、内容特征），不通过就 abort，**绝不写盘**；
- 非唯一锚点要附下一行内容构成唯一（如 `\subsection{促进策略}` 全文有 2 处）。

### 删除区边界

- 上界取到**下一个标题的前一行**，下界取到**下一个同级／上级标题**；
- 删完必须验证 `\begin{itemize}` 与 `\end{itemize}` 配对、无残留孤立 `\item`、无残留未闭合环境。

### 批量插入 `\cite` / `\index` 必须屏蔽已有参数内部（2026-10-19 血泪教训）

**症状**：一行内同一词出现两次（正文一次、`\index{...}` 内一次），简单 `str.replace()` 会同时替换两处，把 `\cite{}` 塞进 `\index{}` 参数内 → **索引条目被污染**（`\index{ICD-11\cite{who2019icd11}}`，`.ind` 会输出一串带反斜杠的垃圾）。

**正确写法**：先用正则把 `\index{[^{}]*}` 整体替换为占位符 → 在未屏蔽部分做替换 → 再还原：

```python
IDX = re.compile(r'\\index\{[^{}]*\}')
spans = []
work = IDX.sub(lambda m: (spans.append(m.group(0)), '\x00%d\x00' % (len(spans)-1))[1], content)
work = work.replace(term, term + '\\cite{key}')
for j, s in enumerate(spans):
    work = work.replace('\x00%d\x00' % j, s)
```

**收尾断言**（不满足即 abort）：`len(re.findall(r'\\index\{[^{}]*\\cite', text)) == 0`，且 `\index{` 总数与改动前一致。

## 五、排版治理

| 问题 | 修法 |
|---|---|
| 三列表格溢出 491pt | `tabular{lll}` → `longtable`（`p{2.6cm} p{3.4cm} p{\dimexpr\linewidth-6.6cm}`） |
| 横向流程图 900pt | 外层包 `\resizebox{\linewidth}{!}{...}` |
| 长英文串不可断 | `\small` + 缩小固定列宽 |
| 裸全角 `──────` 分隔线 | 删除，改用 `\subsection*` |
| **在 `itemize` 内** | `tabularx` 的 X 列与 `p{\dimexpr...\linewidth}` 求值不可靠（`\linewidth` 已缩进），`\resizebox{\linewidth}` 也按未缩进宽度算；**itemize 内一律用固定厘米列宽最稳** |

overfull 基准：0_book 790 处中 640 处仅 4.92pt（表格列间距固有噪声，肉眼不可见），属可接受噪声，不必逐条清理。
